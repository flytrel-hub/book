# Лабораторная работа №8: Построение пирамиды тестирования

## Структура тестов

```
tests/
├── unit/                       # Юнит-тесты (15 тестов)
│   └── store.test.js           # Тесты функций хранения
├── integration/                # Интеграционные тесты (13 тестов)
│   └── api.test.js             # Тесты API-эндпоинтов
├── bookService.test.js         # ЛР6: bad-код (14 тестов)
└── solid/
    └── BookService.test.js     # ЛР6: SOLID (16 тестов)
cypress/
└── e2e/
    └── app.cy.js               # UI-тесты (7 тестов)
```

## Уровни пирамиды

### 1. Unit Tests (15 тестов)

**Что тестируем:** отдельные функции модулей

- `books.getAll()` — получение всех книг
- `books.getById(id)` — поиск по ID
- `books.create(book)` — создание книги
- `books.update(id, data)` — обновление книги
- `books.remove(id)` — удаление книги
- `authors.*`, `categories.*`, `store.*`

**Время:** ~0.4s
**Сложность:** Низкая
**Покрытие:** Функции хранения данных

### 2. Integration Tests (13 тестов)

**Что тестируем:** API-эндпоинты через HTTP-запросы (supertest)

- `GET /api/books` — список книг
- `GET /api/books/:id` — книга по ID
- `POST /api/books` — создание книги
- `PUT /api/books/:id` — обновление книги
- `DELETE /api/books/:id` — удаление книги
- `GET/POST /api/authors`
- `GET/POST /api/categories`

**Время:** ~0.7s
**Сложность:** Средняя
**Покрытие:** Маршруты + валидация + логика обработки

### 3. UI Tests (7 тестов)

**Что тестируем:** поведение в браузере (Cypress)

- Отображение заголовка
- Отображение полей ввода
- Список книг
- Добавление книги через UI
- Удаление книги через UI
- Экспорт данных
- Статистика

**Время:** ~5-10s (зависит от браузера)
**Сложность:** Высокая
**Покрытие:** Полный пользовательский сценарий

## Сравнение

| Уровень | Тестов | Время | Сложность | Покрытие |
|---------|--------|-------|-----------|----------|
| Unit | 15 | 0.4s | Низкая | Функции |
| Integration | 13 | 0.7s | Средняя | API + логика |
| UI | 7 | 5-10s | Высокая | Полный сценарий |

## Запуск

```bash
# Все тесты
npm test

# Только unit
npm run test:unit

# Только integration
npm run test:integration

# Только UI (требует запущенного сервера)
npm run test:ui

# Покрытие кода
npm run coverage
```
